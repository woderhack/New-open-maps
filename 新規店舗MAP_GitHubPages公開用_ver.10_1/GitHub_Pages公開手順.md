# GitHub Pagesで公開する手順(新規店舗MAP)

このフォルダには、公開に必要なファイル一式が入っています。
`index.html` / `manifest.json` / `sw.js` / `icons`フォルダ を、
そのままGitHubのリポジトリ直下にアップロードしてください。

**大事な補足:** アプリの中身(このHTML/JS)には、実際の店舗データや顧客データは
一切含まれていません。データはすべて、使う人がそれぞれ自分のパソコン/スマホの中で
CSVを読み込んで処理する仕組みなので、公開リポジトリを「public(公開)」にしても
顧客情報が外部に漏れることはありません。

## 手順

### 1. GitHubアカウントを作る(お持ちでなければ)
https://github.com/signup にアクセスし、メールアドレスで登録してください(無料)。

### 2. 新しいリポジトリを作る
1. 右上の「+」→「New repository」をクリック
2. Repository name に好きな名前を入力(例: `shinki-tenpo-map`)
3. 「Public」を選択(Privateでは無料プランだとPages機能が使えません。ただし
   前述の通りデータ自体は含まれないので、公開設定で問題ありません)
4. 「Create repository」をクリック

### 3. ファイルをアップロードする
1. 作成されたリポジトリのページで「Add file」→「Upload files」をクリック
2. このフォルダの中身(`index.html`, `manifest.json`, `sw.js`, `icons`フォルダ)を
   まとめてドラッグ&ドロップ
3. 下部の「Commit changes」をクリック

### 4. GitHub Pagesを有効にする
1. リポジトリの「Settings」タブを開く
2. 左メニューの「Pages」をクリック
3. 「Branch」を `main`(または `master`)、フォルダを `/ (root)` に設定して「Save」
4. 数十秒〜数分待つと、ページ上部に公開URLが表示されます
   (例: `https://あなたのユーザー名.github.io/shinki-tenpo-map/`)

### 5. 動作確認
表示されたURLにパソコンのブラウザでアクセスし、地図とサンプル読み込みが
問題なく動くか確認してください。

### 6. スマホでアイコン化する
- **Android(Chrome)**: そのURLを開き、アドレスバー付近に出る「インストール」
  アイコン、または「⋮」メニューの「アプリをインストール」をタップ
- **iPhone(Safari)**: そのURLを開き、下部の共有ボタン(□に↑)をタップ→
  「ホーム画面に追加」を選択

どちらも今回はHTTPSの実サイトになっているため、正しくアイコンが表示され、
ブラウザのアドレスバーなどが出ない独立したアプリのような画面で開けます。

## 更新のしかた
アプリの中身を直したら、同じ`index.html`をGitHubのリポジトリにアップロードし
直す(上書きコミットする)だけで、URLはそのままに全員に最新版が届きます。
アプリを開き直すだけで反映されます(ホーム画面のアイコンは再作成不要です)。

## 補足: URLを短く/独自ドメインにしたい場合
GitHubの「Settings > Pages > Custom domain」から、お持ちの独自ドメインを
設定することもできます(この場合はドメイン側でのDNS設定が別途必要です)。
